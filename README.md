# Lab1_Var1_FlappyBirdClone

**Лабораторна робота №1, Варіант 1**

Проєкт є клоном гри Flappy Bird.

## Особливості гри

- **Анімація**: Плавна анімація помахів крил пташки.
- **Динамічний нахил (Pitch)**: Кут нахилу пташки (pitch) динамічно змінюється залежно від швидкості стрибка або падіння, що додає польоту реалістичності.
- **Випадкові локації**: Фон гри (локація) вибирається випадковим чином при кожному запуску (гори, пустеля, сніговий рівень, цвинтар).
- **Випадкові скіни**: Скін пташки та її колір вибираються випадковим чином із багатьох доступних варіантів під час старту гри.
- **Система балів (Score System)**: Повноцінний підрахунок балів за успішне проходження перешкод із відображенням поточного рахунку на екрані.
